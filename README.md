# Ace Meridian ✈️

AI travel companion. Voice-first travel booking frontend for AgentPay.

Ace is the showcase front door for AgentPay — demonstrating governed payment, identity, and mandate primitives through a travel booking experience.

## Philosophy

Ace should feel:
- I can just ask once
- Ace understands what matters
- Ace stays with the trip
- Ace is calm and in control when things go wrong

## Tech Stack
- React Native (Expo)
- AgentPay Core (mandate, identity, funding)
- Voice-first UX

## Features
- 🎤 Voice-first travel booking
- ✈️ Multi-leg journey planning
- 🏨 Hotel + transport bundling
- 🔐 Governed payment via AgentPay
- 📍 Real-time rerouting
- 🔄 Journey continuity and resume

## Pricing

- **Free**: Basic search and booking
- **Pro ($19/mo)**: Premium support, rerouting, multi-leg
